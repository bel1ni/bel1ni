## About Me

I'm **Mariane**, a full-stack software developer passionate about crafting clean, efficient, and user-friendly applications for the web and mobile. I enjoy working across the whole stack — from building responsive interfaces to designing solid backend logic — and I'm always exploring new tools and languages to sharpen my craft.

- 💻 Focused on **JavaScript / TypeScript**, building with **React** and **React Native**
- 🎨 Strong foundation in **HTML & CSS** for pixel-perfect, responsive UI
- 🗄️ Working with **Supabase** for backend and database-driven apps
- 🐍 Comfortable with **Python** for scripting and automation
- 🎮 Exploring **Lua** for game and embedded scripting
- 🌱 Constantly learning and refining my development workflow with **Git**
- 💬 Open to collaborating on interesting full-stack and mobile projects
